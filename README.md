Custom HTML & CSS Visuals
One of the main features of this project is the use of HTML and CSS inside Power BI to create custom visuals beyond the standard Power BI charts.
👤 Custom Player Card
A dynamic player card was created using:
- HTML
- CSS
- Dynamic DAX Measures
The card displays:
- Player Name
- Team
- Rank
- Goals
- Player Image
- 
The displayed information changes dynamically according to the selected player.
🔵 Top Scorers Orbit
A custom Top Scorers Orbit was created using HTML/CSS and DAX.
The visual displays the top 10 goalscorers around a central player card.
The orbit includes:
- Player images
- Player ranking
- Selected player
- Team
- Goals
- Dynamic selection
  
This allowed the dashboard to provide a more interactive experience than traditional Power BI visuals.
